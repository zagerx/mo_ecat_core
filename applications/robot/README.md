# 机器人应用层

本目录保存机器人的领域对象代码，刻意与 `mo_ecat_core` 分离：
核心库只负责扫描 EtherCAT 从站；本层负责把扫描结果映射为机器人功能组和关节。

规划流程：

```text
扫描完成后，主站仍保持 IDLE
  → 读取机器人配置
  → 匹配已扫描从站
  → 构建 `struct robot robot_instance`
  → 校验功能组与关节
 → 后续应用 PDO/DC 配置
```

运行时对象使用 `struct robot`，当前机器人实例使用变量名
`g_robot`。该对象保存机器人名称、关联主站、已匹配关节和功能组；
它不拥有主站的生命周期。

配置文件中的从站匹配条件应使用 `alias`、`position`、厂商 ID 和产品码；
运行时 `slave_index` 仅表示本次扫描结果中的数组下标，不能作为永久配置身份。
